# Fixture — plantilla copiada sin editar la forma

Etapa armada copiando `templates/CONCILIACION.md` y `templates/TAREAS.md` y
rellenando los huecos, sin retocar la forma de los campos. El validador tiene
que aceptarla tal cual: la plantilla es el ejemplo que una persona copia, y si
el validador exige otra forma, la plantilla enseña a fallar.

Los roces que esta fixture fija (S69): el tipo del CA entre corchetes, el
`Test:` escrito entre acentos abiertos y el runner declarado como frase con su
aclaración entre paréntesis.
