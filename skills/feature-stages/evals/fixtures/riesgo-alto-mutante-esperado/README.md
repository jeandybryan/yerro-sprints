# Fixture — mutante declarado en futuro

Riesgo `alto`, presupuesto sancionado, caso límite y una prueba de mutación
escrita como **predicción**: `mutante: separador invertido → rojo esperado`.

Debe **fallar**. `evidence.md` §2 lo dice explícitamente: *"Debería fallar si…:
una predicción no es una observación"*. Aceptar `rojo esperado` convertiría el
gate en una promesa del agente sobre lo que el test haría, que es exactamente
lo que B-35 existe para no aceptar.

El único defecto es la forma del resultado: sin él, el resto del ledger está en
orden.
