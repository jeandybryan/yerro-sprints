# Fixture — riesgo alto sin la evidencia que el nivel exige

Conciliación y auditoría en riesgo `alto`, y un ledger que demuestra
sensibilidad con `revertir → rojo → restaurar` pero **no** declara ni caso
límite ni prueba de mutación.

Debe **fallar** por los dos huecos: el fondo que exige `alto` no es opcional.
