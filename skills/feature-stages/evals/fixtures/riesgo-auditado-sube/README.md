# Fixture — el auditor sube el riesgo

La conciliación declaró `bajo` y la pasada auditada declara `alto`. El
contrato deja al auditor **subir** el riesgo; si la subida no cambia lo que el
cierre exige, la frase es decorativa. El riesgo efectivo es el mayor de los
dos: la pasada `alto` exige un `mutante:` observado en rojo, y este ledger no
lo trae. El control es `valid-stage`, donde conciliación y pasada coinciden en
`medio` y el cierre pasa.
