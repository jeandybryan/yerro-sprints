# Fixture — riesgo bajo sin test-first

Riesgo `bajo`, una tarea sin `Test-first:`.

Debe **fallar** (P22): el riesgo proporcionaliza la **revisión**, no la prueba.
Test-first y sensibilidad se exigen en todos los niveles; si con riesgo bajo se
pudiera prescindir de la prueba, `bajo` sería una forma barata de no probar.
