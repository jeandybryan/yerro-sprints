# Fixture — tarea con cuatro rulings

Una tarea que acumula **cuatro** rulings no resuelve ambigüedad residual: es una
tarea sin especificar disfrazada de tarea. `doctor.py` debe avisarlo y apuntar a
`generate-stage-tasks`, pero **no bloquear**: un ruling de migración puede ser
legítimo y partir la tarea en cuatro de una línea sería peor (B-33).
